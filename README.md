# 💳 Loan Risk Prediction & Financial Copilot

End-to-end machine learning pipeline and predictive model designed to assess credit risk, handle missing financial data, and optimize decision-making thresholds for loan portfolio management.

## 🚀 Overview
This repository contains a comprehensive data science workflow aimed at predicting loan defaults. Built with robust preprocessing, missing value imputation, and recall-optimized threshold tuning, the project serves as an analytical financial assistant (Financial Copilot) to help mitigate credit risk.

## 🛠️ Tech Stack & Libraries
* **Language:** Python
* **Data Manipulation & Processing:** Pandas, NumPy, Scikit-Learn
* **Imputation:** MICE (Multivariate Imputation by Chained Equations)
* **Modeling / Algorithms:** CatBoost, Random Forest, or related classification frameworks
* **Deployment (Interface):** Streamlit / Hugging Face Spaces

## 📊 Key Features
* **Advanced Data Preprocessing:** Rigorous handling of outliers and missing financial parameters.
* **MICE Imputation:** Statistical imputation to preserve dataset distribution and integrity.
* **Recall-Optimized Threshold Tuning:** Fine-tuned decision boundaries to prioritize the identification of high-risk defaults, minimizing financial exposure.
* **Stress Testing & Validation:** Automated validation controls to prevent data leakage and ensure model generalizability.
